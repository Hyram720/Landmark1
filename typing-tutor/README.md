# Home Row — typing tutor

A self-contained touch-typing course in a single file (`index.html`). Open it in any browser; no build step or server needed.

- **Lessons** — 22 lessons that add two keys at a time: home row, top row, bottom row, then capitals, numbers, punctuation and full sentences. Each lesson awards up to 3 stars (90% accuracy to pass; speed goals rise as you go).
- **Weak keys** — a drill generated from the keys you miss most often.
- **Speed test** — 30 s, 1 min or 2 min of real sentences.
- On-screen keyboard color-coded by finger, highlighting the next key (and which Shift to use).
- Live WPM and accuracy. Mistakes must be corrected before moving on.
- Progress, stars and per-key stats are saved in the browser's localStorage.

Shortcuts: `Esc` restarts, `Enter` continues after a result.
