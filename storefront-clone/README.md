# Storefront clone (local demo)

A one-file landing page modeled on the layout of shopify.com's homepage. It has a placeholder brand, original text and drawn-in graphics. No Shopify logos, images or copy are included.

## Open it on your laptop

1. Get the file: `git clone https://github.com/Hyram720/Landmark1.git` (or download `storefront-clone/index.html` from GitHub).
2. Double-click `storefront-clone/index.html`. It opens in your browser and works offline, with no install.

## Make it yours

- **Brand name:** change `const BRAND = "Cartwell";` near the bottom of `index.html`. Every mention updates.
- **Colors:** edit the variables at the top of the `<style>` block (`--brand`, `--accent`, `--ink`).
- **Example stores, stories and numbers:** these are placeholders. Replace them with your own real ones before publishing.
- **Sign-up form:** demo only, nothing is sent anywhere. Point it at a real backend before going live.
