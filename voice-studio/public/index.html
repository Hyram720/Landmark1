Sun Voice Studio

Live agents run on Phonic-1, a speech-to-speech model that hears you and answers out loud in real time. To turn them on, create a key at phonic.ai, add PHONIC_API_KEY=... to .env, and restart the studio. You can set up agents below meanwhile.

Ready when you are.

Use headphones for the most natural back-and-forth. You can interrupt the agent any time, just like a real call.
