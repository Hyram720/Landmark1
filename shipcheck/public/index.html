What it catches

🔑 Leaked API keys

OpenAI, Anthropic, Stripe, AWS, GitHub, Google and more, committed in code or in .env files.

🗄️ Open Supabase tables

Tables without Row Level Security, policies of using (true), and service_role keys in the browser.

💳 Fake-able payments

Stripe webhooks that never check the signature, so anyone can "pay" with a forged request.

🌐 Secrets in the frontend

NEXT_PUBLIC_ / VITE_ variables holding secrets, and AI SDKs running in the browser.

🔥 Open Firebase rules

allow read, write: if true lets anyone dump or wipe your database.

🧹 Launch hygiene

Missing .gitignore entries, CORS wildcards with credentials, raw HTML rendering, no lockfile.

How it works

1. Free scan

Paste a repo link or upload a zip. In about 30 seconds you see your score and what's wrong.

2. Unlock the fixes ($19)

Get the exact file and line for each problem, why it matters, and how to fix it.

3. Paste and ship

Every finding has a fix prompt for your AI coding tool. Re-scan free to confirm it's clean.

ShipCheck is an automated static check, not a full security audit or a guarantee. It catches common, costly mistakes before launch.
