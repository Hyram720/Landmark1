# Reference sheet prompts

Rule: **anything that appears twice gets its own sheet.** Save to `sheets/<name>.png`.

## Character sheet
```
Character reference sheet of <NAME>, <age>, <build>, <hair>, <outfit>,
always wearing <UNIQUE DETAIL>. Three panels on a plain flat grey background:
(1) full body from the front, face turned away or in shadow,
(2) full body from the back,
(3) head-and-shoulders close-up of the face, neutral expression, even light.
<FILM LOOK>. No text, no other people.
```
Why the face is hidden in the full-body panels: the video model should see only **one** face, the close-up.

## Place sheet
```
Empty <PLACE> interior/exterior, <key furniture/details>, no people.
<FILM LOOK>. Vertical 9:16, eye-level wide shot.
```

## Prop sheet
```
Close-up product-style shot of <PROP> (<material, color, distinctive mark>)
on a plain grey background. <FILM LOOK>. No hands, no text.
```
